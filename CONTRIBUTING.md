# Contribution workflow
1. Create a YouTrack task with owner, deadline, priority, expected result and acceptance criteria.
2. Branch from updated `main`: `git switch -c DIP-12-literature-review` (replace DIP-12 with your actual issue ID).
3. Make small, meaningful commits: `git commit -m "DIP-12: Add reviewed research sources"`.
4. Push branch and open a pull request. Link the YouTrack task and explain how the work was verified.
5. Ask another team member to review before merging into `main`.
6. Link PR/commit in YouTrack; close only after acceptance criteria pass.
7. At first pre-defense, tag the reviewed submission `pre-defense-1` and push the tag.

Use personal GitHub accounts; never share credentials. Do not fabricate contribution history or backdate commits.
